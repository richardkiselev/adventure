# What the project is 
Coded in Python. An adventure game where you explore a trail into the woods... There are 3 (intro to 4) chapters: bugs, goblins, slimes, and fungi! Started as a text adventure, but I added a screen/window with Pygame and all sorts of stuff. Generally fun and lighthearted. 
# How you built it
Coded entirely in Python. VS Code as my IDE. I did use Copilot for some stuff, mainly implementation of new libraries such as pygame. I learned Python when I was like 8 years old and forgot some of the technical stuff. Hackatime shows it as only like 5% of total time, though.

# How to run it
Download the .exe file and run it. Simple as that. You need a keyboard.
